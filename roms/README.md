# ROMs

Put dumps of your own N64 cartridges here as zip files. This repo doesn't include any games.

The shelf shows each game from `public/js/packs/games.js` whose zip is in this folder, so reload the TV page after adding one. The names it looks for:

| File | Game |
| --- | --- |
| `marioparty2.zip` | Mario Party 2 (Europe) |
| `marioparty3.zip` | Mario Party 3 |
| `mariokart64.zip` | Mario Kart 64 |
| `smash.zip` | Super Smash Bros. |
| `mariotennis.zip` | Mario Tennis |
| `mariogolf.zip` | Mario Golf |
| `bomberman64.zip` | Bomberman 64 |
| `pokemonstadium.zip` | Pokémon Stadium |
| `pokemonstadium2.zip` | Pokémon Stadium 2 |
| `goldeneye.zip` | GoldenEye 007 |

The "whose turn is it" feature reads RAM addresses that only match the European Mario Party 2. Other versions play fine, but the phones won't know whose turn it is.

Anything in this folder except this file is ignored by git.
